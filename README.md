# MtD-open-source
!! RELEASED UNDER THE GNU GPU v3 LICENSE !!

Official development of MtD is over and so we are releasing it to the public!
Feel free to mod the game and share modifications to your liking, remember about credit and keeping your modifications open source.

If you are going to publish a copy of the game, please add "Modded" or "Unofficial" to the game title

This repository contains the MtD Studio file with all code and map assets present, it of course does not include audio, animation, decal and texture assets as that would be too troublesome to package.
